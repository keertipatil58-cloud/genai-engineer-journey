# Day 7 – Python Object-Oriented Programming (OOP)

## 📌 Overview
Today I learned the fundamentals of Object-Oriented Programming (OOP) in Python. OOP helps organize code using classes and objects, making programs easier to understand, reuse, and maintain.

## 📚 Topics Covered

### 1. What is OOP?
- OOP stands for Object-Oriented Programming.
- It is a programming approach based on classes and objects.
- It helps organize code into reusable structures.

### 2. Classes
- A class is a blueprint for creating objects.
- It defines attributes and methods.
