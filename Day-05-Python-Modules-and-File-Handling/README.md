# Day 5 – Python Modules, Imports and File Handling

## 📌 Overview

On Day 5 of my GenAI Engineer learning journey, I learned how to use Python modules, import reusable code, and work with files to store and retrieve information.

## 📚 Topics Covered

### 1. Python Modules
- What is a Python module?
- Importing complete modules using `import`.
- Importing specific functions using `from ... import`.
- Using aliases with `as`.

### 2. File Handling
- Opening files using `open()`.
- Reading files using `read()`.
- Writing content using `write()`.
- Closing files using `close()`.
- Using `with open()` for automatic file closing.

### 3. File Modes

| Mode | Purpose |
|---|---|
| `r` | Read an existing file |
| `w` | Write content and replace existing content |
| `a` | Append new content without deleting old content |
| `x` | Create a new file |
